# SanimarcInc/.github

Fichiers par défaut de l'organisation. Tout repo qui n'a pas ses propres fichiers en hérite automatiquement :

- `.github/pull_request_template.md` : template de PR
- `.github/ISSUE_TEMPLATE/` : formulaires d'issue (bug, fonctionnalité, tâche)
- `CONTRIBUTING.md` : le standard de travail (branches, PR, commits, AI)

Ressources à copier dans chaque repo :

- `templates/AGENTS.md` : instructions pour les agents AI (Claude, Codex, Copilot, Cursor…)
- `templates/CLAUDE.md` : importe `AGENTS.md` pour Claude Code
- `templates/pr-guard.yml` : appelle le contrôle automatique des PR (`.github/workflows/pr-guard.yml`)

> Ce repo est public parce que GitHub l'exige pour les fichiers par défaut. **N'y mettez jamais de code, de secret ni d'information interne.**
